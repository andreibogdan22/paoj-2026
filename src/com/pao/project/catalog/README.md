# Proiect PAO - Etapa I: Catalog Școlar

## 1. Acțiuni / Interogări posibile în sistem (10 acțiuni)
1. Adăugarea unui student nou în sistem.
2. Căutarea unui student după numărul matricol.
3. Ștergerea unui student din sistem.
4. Listarea tuturor studenților (sortați alfabetic).
5. Adăugarea unei materii noi în programă.
6. Căutarea unei materii după codul ei.
7. Ștergerea unei materii.
8. Listarea tuturor materiilor disponibile.
9. Adăugarea unei note pentru un student la o materie.
10. Afișarea situației școlare (catalogului) unui anumit student.
